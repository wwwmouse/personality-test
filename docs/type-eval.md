## 根因分析

1. **E/I 结构性短板（最大问题）**：判断题（★★★★★/★★★★☆）只有 T/F 槽位，感知主导型（ENxP / ESxP）的主导功能 Ne/Se 在权重最高的题里无处安放；辅助 Fi/Ti 信号反而拉满 → 按"E/I 由主导功能方向推导"的规则，辅助内倾功能被误当主导 → E 判成 I。真实 ENFP 用户也会中招（判成 INFP）。
2. **Fi 信号弱**：Fi 槽位最少（4.5 个，八维倒数第一）；且 Q18-B"坚持用数据说话"文案 T 味重，但权重表标 Fi/Te——文案与映射打架，F 型人 3/16 被误判 T。
3. **Se 与 Ne 混槽**：Q1-D / Q7-A / Q19-C 都是"Se+Ne"混合槽位，Se 主导型信号被稀释，漏到 N 侧。
4. 档案局限：教科书档案只含选项、理由留空，是判型能力的**下限**；真实用户写理由后准确率会更高，但结构性短板不因理由而消失。

## 修复清单（题目 v2.1 专场，按优先级）

1. **给感知主导型补高权重证据**：在 ★★★★★ 判断题中混入外倾感知表达，或把 Se/Ne 混合选项拆开——让 Ne/Se 主导者有高权重选项可站
2. **prompt 加 E/I 纠偏规则**：判断题与感知题信号矛盾时按权重比例综合，不单凭判断题定 E/I
3. 修 Q18-B 文案的 T 味（或改权重表标注）
4. 找一题补一个 Fi 槽位
5. 重跑本回归集验收，目标：E/I ≥ 14/16，全对 ≥ 10/16
