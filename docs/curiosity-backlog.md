## A. AI 应用核心（主线技能，最该优先补）

1. **结构化输出：json_object vs json_schema、验货重写模式** ★★★【已实战，8-16】
   出处：DeepSeek 不支持 json_schema → 后端自己当质检员（验货+退货重写，最多 3 次）。
   为什么重要：让 LLM 输出"可解析、可校验的数据"是 agent 开发的地基（function calling 是同一件事）。
   建议深度：动手练习——把"验货员"逻辑推广成通用模块，或者对比学一下支持 json_schema 的模型怎么写。

2. **prompt 迭代方法论与评估思维** ★★★【已实战一半，8-16/8-17】
   出处：金句规范升级就是一次完整迭代（给标准 + 给示范 + 给反例清单 → 实测对比 → 拍板）。
   缺的一半：系统性地评估 prompt 质量（多组输入、打分、对比），而不是"感觉还行"。
   建议深度：弄懂原理——对应学习地图 Stage 2。

3. **系统提示词：few-shot、CoT 等进阶技巧** ★★★【部分已实战】
   出处：prompt.md 已用了角色定义、格式合同、红线、金句示范；还没系统用过 few-shot 完整案例、思维链。
   建议深度：按学习地图 Stage 2 系统走一遍，用本项目当练手材料。

## B. 后端与网络（web 地基）

4. **async/await、Promise、fetch** ★★★【已实战，8-16 起处处在用】
   出处：调 DeepSeek、记账、反馈，全在这套语法上。
   为什么优先：它是所有前后端代码的"通用语法"，不弄懂它，读任何代码都瘸腿。
   建议深度：动手练习。

5. **HTTP 状态码体系** ★★【已实战，8-16】
   出处：401/402/429 翻译成人话、400/500/502 责任划分。
   建议深度：懂个大概，半小时课。

6. **中间件 middleware** ★★【出处 8-16】express.json() 那行。
   建议深度：弄懂原理——"请求进门要过安检链"的模型。

7. **跨域 CORS 与代理** ★★【已实战，8-16】浏览器"不许跨窗口说话"→ Vite proxy 中转；上线后同域天然无此问题。
   建议深度：弄懂原理。

8. **环境变量与启动参数** ★★【已实战，8-16】process.env、--env-file-if-exists、Vercel 环境变量；key 永不进仓库的纪律。
   建议深度：懂个大概即可（纪律已经会了）。

9. **回调函数 vs 事件驱动模型** ★★【出处 8-15】已口头讲过时间线比喻。
   建议深度：弄懂原理，一小时课。

10. **AbortSignal.timeout 超时保护** ★【出处 8-16】120 秒没回就放弃。
    建议深度：懂个大概。

11. **import.meta.dirname / path.join 路径处理** ★【出处 8-16】跨文件夹找 prompt.md 的姿势。
    建议深度：随用随学。

12. **Redis 键值数据库与原子计数** ★★【出处 8-17 统计埋点选型】
    出处：当时选了 Blob 走主线，Redis 记入本清单；流量大了换 Redis 只改 stats-store.js 一个文件。
    为什么值得学：就业硬通货（"会用 Redis 计数"是常见面试题）；INCR 天然原子，解决账本并发短板。
    建议深度：动手练习——换仓库那天就是它的开学日。

13. **serverless"失忆"与外部存储** ★★★【已实战，8-17】
    出处：函数"来客才醒、醒了就睡"，本地文件靠不住 → 账本必须存云端仓库。
    建议深度：已实战过，补一次原理课即可。

## D. 部署与工程

21. **DNS 全景：A / CNAME / NS / TTL、污染与 SNI 连坐封锁** ★★★【已实战三次，8-17】
    出处：vercel.app 被整条街拉黑 → 买域名 → 配两条记录 → 全球生效；微信未备案限制（国情课）。
    为什么值得学：你已经亲身经历了完整故事线，系统串一遍这门课就是你的了。
    建议深度：弄懂原理。

22. **OIDC 一次性通行证** ★★【已实战，8-17】新版 Blob 无长令牌，运行时现场领短效通行证。
    建议深度：弄懂原理——"为什么不发长钥匙更安全"。

23. **nft 按需打包机制** ★★★【已实战两次，8-17 与 8-20】升级为必修课：
    第一遍（8-17）：express 没上飞机——Vercel 打包函数只看根目录行李清单，server/ 依赖要 build 时安装。
    第二遍（8-20）：app.js 用 fs 运行时读前端题库 JSON → 文件不在 includeFiles → 函数启动即崩，全部 /api/* 挂掉（提交失败+stats 登不上同一根因）。解法：改静态 import（nft 必打包静态依赖）。
    规律一句话：**运行时读的文件必须登记（includeFiles），静态 import 才不用登记**。
    建议深度：弄懂原理——这已经是第二次交学费，值得半小时把它彻底拿下。

24. **CI/CD 与自动部署** ★★【已实战，8-17】push 即上线（GitHub 通知 + Vercel 干活）。
    建议深度：弄懂原理，半小时课。

25. **git tag 与 GitHub Releases 的版本仪式** ★★【预告：v1.0 时实战】
    建议深度：动手练习——1.0 那天学，仪式感拉满。

26. **版本号纪律与 commit 信息原则** ★【已口头讲过，8-16】版本号 = 仓库里程碑、commit 只写动作。
    建议深度：已掌握。

27. **社交分享卡片 og 标签** ★【已实战，8-17】微信未备案限制已确诊，og 通用标签保留中。
    建议深度：懂个大概；备案专场时深挖微信生态。

28. **微信生态与 ICP 备案** ★【背景知识】未备案域名在微信内弹风险提示、链接不显示卡片。
    建议深度：改天备案专场（腾讯 EdgeOne 路线）再学。

29. **浮点误差与阈值比较** ★★【已实战，8-20】
    出处：ESFJ 分差恰为 0.70，浮点累加把它算成 0.6999999999999993 → 误入平手区；scorer 已按"分差四舍五入一位再比阈值"修正。判型账本这种"0.7 定生死"的地方，浮点误差就是隐性 bug。
    建议深度：懂个大概，半小时课（顺带讲：钱的计算为什么用整数分不用浮点元）。

## E. 建议的学习顺序（结业路线）
