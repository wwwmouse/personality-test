# 人格测试网站 · 产品说明书

> 更新日期：2026-08-20 ｜ 阶段 0 产出 ｜ 维护：www 与 Claude

## 1. 产品定位

- 一个娱乐向的 MBTI 人格测试网站
- 用户答 20 道混合制题目 → AI 生成专属人格报告
- 定位娱乐产品，报告页含免责声明
- 口号："不止于MBTI"（暂定，可随时调整）——差异化押在更深解读 + 专属报告，不是"测 MBTI"（测八维是入场券，人人都有）
- 魔法盒子原则（不喊 AI）：引擎是 AI 属于内部知识（同计分权重）；产品文案永不主动把 AI 当卖点——避免用户产生"那我直接问 AI 不就行了"的祛魅

## 2. 玩法

MBTI 式：由八维认知功能（毕比模型）推断四字母类型。不是四个维度独立计分。

## 3. 答题形式（混合制，定稿）

每道题 = **情境选择题（2~4 个选项）+ 可选理由框（1~2 句）**

- 选择题提供快速信号，由代码按选项标签计分（选项账本，v3.0 起）
- 理由框是 AI 分析的原料——同一个选项，不同理由 → 不同人格
- 两道核心推断题（Q1、Q2）**理由必填**（占位文案：功能性提示）；其余题选填，用自然轻量的钩子引导（顺口不造作；没有好钩子的题就老老实实问为什么）
- 判型由代码账本 + 三区裁决决定（选项优先；平手区由理由定主辅，见 docs/prompt.md 第 3 章）；八维解读与报告文字由 AI 完成——AI 是理由的唯一读者、报告的唯一作者（v3.0 修订）

## 4. 报告结构（v2.3，2026-08-19 更新）

1. 四字母类型 + 类型别称（如 ENFP · 追梦人）
2. 金句：一句话总结，设计成可截图的分享钩子——有画面感、抓人、不套话
3. 一段人格描述（400 字左右，生动具体）
4. 八维功能解读（阳面四功能，毕比模型原型名：英雄 / 父母 / 永恒少年 / 阿尼玛/阿尼姆斯；每项 3~4 句 + 生活化例子，禁止逐题复述；各配 0~100 强度分，主导最高、劣势最低）
5. 压力下的你（阴影功能专章，三段式：压力按钮 + 高压之下 + 风暴过后，各 100~120 字，结合阴影题：第 3、8、13、15、19 题）
6. 类型配对（两项格子：合拍 / 火花各带详细解释 100~150 字 + 一个具体生活场景 100~150 字，合计 400~600 字）
7. 免责声明

两条已定的红线（v2 仍有效）：

- **不引用用户原话**（保护分享者隐私，报告可放心转发）
- **不展示推断逻辑**（哪题测哪个功能、怎么推断的——内部知识，读者无需知道）

v2 新增模块同样受反巴纳姆约束："压力下的你"、"类型配对"必须从答题里长出来；金句禁止放之四海而皆准的套话。

## 5. 题目设计原则

1. 情境选择题，不是李克特同意度
2. 一道题可同时暴露 2~3 个功能，20 题覆盖八维（题目 v2.1 起：15 阳面 + 5 阴影）
3. 题目文字不标注所测功能
4. 原创自编——MBTI 官方题本有版权，不可抄
5. 其中挑 2 道作为"核心推断题"，理由框建议多写几句
6. 计分策略（v3.0）：每选项单标一个认知功能；八维等预算——I 侧（Ti/Fi/Ni/Si）8 槽×0.7、E 侧（Te/Fe/Ne/Se）7 槽×0.8，每功能总分各 5.6；判型 = 最高分功能定主导（三区裁决见 prompt.md 第 3 章）。预算均衡从根上消灭"感知/判断"跷跷板（v2 的"感知低权重、判断高权重"正是 E/J 型翻车的病灶）
7. 选项写行为，理由写动机——功能信号藏在动机里；选项把"为什么"讲完，理由框就没戏了
8. 题目是数据非代码：v1 先用，后期换题零成本（换题只换 JSON；选项的功能标签与权重也在 JSON 里）

## 6. 题目模板（每题照此格式）

```markdown
### 第 N 题
题干……

A. 选项一
B. 选项二
C. 选项三

（可选）为什么这么选？一两句话即可
```

核心推断题在题干前加标记：`### 第 N 题（核心）`
