# 人格测试项目 · 零基础学习路线

> 面向：有 Python/sklearn/PyTorch 基础、没学过 Vue/JS 语法的大二读者（项目作者本人）。
> 目的：不深挖前端语法，用约 8~12 小时把本项目内化成"能讲、能改、能迁移"的能力。
> 用法：按阶段推进，每阶段产出交给带教（AI）检验；检验问题先自己答，答不上来=还没懂，回去再看。
> 项目自身文档（product-spec / architecture / recap / type-eval / prompt）始终是权威。

---

## 0. 这个项目是什么（30 秒版）

网页版 MBTI（荣格八维）人格测试：
1. 用户答 20 道情境题（每题：选一个选项 + 写一段理由）；
2. 后端用**代码**把选项算成"八维账本"（确定性判型骨架），再调用 AI（DeepSeek）读"答案 + 账本"生成个性化报告；
3. 后端按"格式合同"逐项验货，不合格退回让 AI 重写（最多 3 次）；
4. 报告返回前端展示；同时只记一笔"聚合数字"统计（不存答案原文）。

餐厅比喻：`frontend/` = 店面（用户看到的一切），`server/` = 后厨（调 AI、验货、记账），`docs/prompt.md` = 给 AI 大厨的菜谱，`vercel.json` = 线上开店合同。

## 3. Vue/JS 魔法词速查表（40 分钟量级，够用为止）

| 魔法词 | 白话意思 | 在项目里长什么样 |
|---|---|---|
| `.vue` 文件 | 一个"零件"：结构（template）+ 逻辑（script）+ 样式（style） | `QuestionItem.vue` = 单道题的零件 |
| `v-for` | 列表里每个元素都渲染一遍 | `v-for="q in questions"` 画 20 道题 |
| `v-model` | 输入框的值实时存进变量 | 选项/理由框 |
| `@click` | 点按钮执行这个函数 | `@click="handleSubmit"` |
| `v-if / v-else` | 条件满足才显示这段 | 按 `phase` 切换画面 |
| `ref()` / `computed()` | 会变的数据 / 自动算出的数据 | `phase`、`progressPct` |
| `fetch` | 浏览器向后端发请求 | `fetch('/api/analyze')` |
| `props` | 父组件把数据传给子组件 | `:question="q"` |

> 不用学 Vue 语法。这 8 个词认全，前端就能读懂 80%。

## 4. ML 知识迁移表（学起来减半）

| 你会的 | 项目里的对应 |
|---|---|

| 过拟合 | 温度随理由填写率走（信号弱→保守）= 防 AI 乱猜 |
| 超参调优 | `temperature`、重试次数、`maxDuration` |

## 5. 给导师展示的推荐顺序

1. **personality-test**（5 分钟主场）：20 道题 → AI 出报告；三个关键决策——判型交给代码（五测 16/16）、后端验货重写（AI 输出不可信）、部署上线（Vercel + KV + 环境变量）；现场打开线上地址。
2. **CNN 项目**（3 分钟）：拿"数据增强让 train loss 变差但 test 变好"这个反直觉现象讲过拟合。
3. **titanic**（2 分钟）：两个关键词——数据泄露、特征工程天花板。
